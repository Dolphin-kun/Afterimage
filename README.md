# 「残像」プラグイン

### [最新バージョンをダウンロード](https://github.com/Dolphin-kun/Afterimage/releases/latest)

## 概要
アイテムに残像を発生させるプラグインです。
バージョンチェッカー入ってます。

## 使い方
1. アイテムを追加して、`アニメーション`カテゴリーにある「残像」を選択して追加してください。

## 効果
### フレーム数
保存するフレームの数です。
`持続フレーム`よりも大きくする必要はありません(見えないから)。

### 持続フレーム
残像が表示されてから、完全に消えるまでの時間(フレーム)です。

### 減衰
減衰をするかどうかです。
有効にしたら`不透明度`が表示されます。

### 不透明度
残像の不透明度です。
